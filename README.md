# Basic CRM

Proyecto personal enfocado en la construcción de un CRM desde cero utilizando PHP, con el objetivo de desarrollar una base sólida y reutilizable tipo mini-framework (MVC + Routing + Active Record).

> ⚠️ Estado actual: En desarrollo temprano. No es un proyecto listo para producción.

---

## 🎯 Objetivo del proyecto

Este repositorio no busca ser únicamente un CRM, sino una base de arquitectura reutilizable para futuros proyectos personales.

Enfoque principal:

- Entender y construir un Router propio
- Implementar un patrón Active Record personalizado
- Definir una estructura modular escalable (MVC-like)
- Aprender buenas prácticas de organización de código backend en PHP

---

## 🧱 Estructura del proyecto

```bash
basic-crm/
│
├── config/         # Configuración de la aplicación (DB, bootstrap)
├── core/           # Núcleo del sistema (Router, ActiveRecord, etc.)
├── controllers/    # Controladores (pendiente)
├── models/         # Modelos (pendiente)
├── middleware/     # Middleware (pendiente)
├── domain/         # Lógica de dominio (pendiente)
├── helpers/        # Funciones auxiliares globales
├── public/         # Entry point (index.php)
├── vendor/         # Dependencias de Composer
│
├── composer.json
└── README.md
```
